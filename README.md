# クリックポストCSVメーカー（20260907）

Amazon自己発送の宛先を**貼り付けるだけ**で振り分けて、クリックポストの「まとめ申込」に上げるCSVを作るスマホ用アプリ。

## 何を解決するか

クリックポストは1件ずつフォーム入力すると死ぬほど時間がかかる。
公式に**「まとめ申込」＝CSVを1回上げれば40件まとめて登録**できる口があるので、そのCSVをスマホで作れるようにした。

## 使い方（3手）

1. セラーセントラルの宛先をコピーして、アプリのテキスト欄に貼る（何件でも・空行区切りは任意）
2. 「振り分ける」→ 郵便番号 / 氏名 / 住所1〜4 / 内容品 に自動で分かれる（違ってたらその場で直す）
3. 「リストに追加」→ 溜まったら「CSVを作る」→ ファイルに保存
4. クリックポスト →「まとめ申込」→「ファイルを選択」→ 保存したCSVを選ぶ

## 振り分けのルール

| 入力 | 判定 |
|---|---|
| `560-0036` `〒5600036` | 郵便番号（ハイフン有無どちらでも・出力は7桁） |
| `大阪府` | 都道府県 → 住所1行目 |
| `豊中市蛍池西町` | 市区町村 → 住所2行目 |
| `1-2-5` | 番地 → 住所3行目 |
| `パークサイドマンション302` | 建物 → 住所4行目 |
| `山本勝久` | 氏名（数字なし・住所語なし・建物語なしでスコア判定） |
| `090-1234-5678` | 電話番号 → **捨てる** |
| `日本` `JP` | 国名 → **捨てる** |

- 順番はバラバラでもいい（氏名が先頭でも末尾でもOK）
- 「渋谷区, 東京都 150-0041」のようなカンマ結合行も割る
- 空行が無くても、2つ目の郵便番号の手前で自動的に次の1件として切る
- 住所は **市区町村 → 番地 → 建物** の順に並べ替えてから4行に詰める

## クリックポストの仕様（公式PDFより・2026-09-07確認）

| 列 | 中身 | 制限 |
|---|---|---|
| A | お届け先郵便番号【必須】 | ハイフンなし半角7桁 or ハイフンあり8桁 |
| B | お届け先氏名【必須】 | 全角20字（敬称除く） |
| C | 敬称 | 「様」or「御中」 |
| D〜G | 住所1〜4行目【いずれか必須】 | **各行 全角20字** |
| H | 内容品【必須】 | 全角15字 |

- ファイル形式：CSVのみ（.xlsx / .txt は不可）
- **文字コード：Shift-JIS**
- 1回のアップロード上限：40件（41件以上は自動で複数ファイルに分割して出す）
- ヘッダー行は改変NG

出典：https://clickpost.jp/create_csv_manual_yahoo.pdf

## デスクトップ（Chrome拡張）

Chromeの**右上の拡張アイコン**を押すとその場で開く。セラーセントラルを見ながらコピペして使う。

### 🛑 Amazonのページには一切触らない

これは意図的な設計。2026-09-07に貴斗さんの判断で決めた。

- `content_scripts` なし ／ `host_permissions` なし ／ `permissions` なし
- Chromeの拡張詳細画面で「**サイトへのアクセス：なし**」と出るのが正しい状態
- 理由：Amazonの利用規約には自動収集ツールの禁止条項がある。実際にどう運用されるかは断言できない。断言できないものに本せどりのアカウントは賭けない。浮くのは1件30秒で、割に合わない
- ⚠️ 将来ここに「セラセンから自動で吸い出す」を足したくなったら、**この判断ごと読み直すこと**

### 入れ方（初回だけ）

1. Chromeで `chrome://extensions` を開く
2. 右上の「**デベロッパーモード**」をオン
3. 「**パッケージ化されていない拡張機能を読み込む**」→ このフォルダの中の `chrome-extension/` を選ぶ
4. ツールバーのパズルピース → ピン留めすると右上に常駐する

### 直すとき

- **`chrome-extension/` の中は複製。直接触らない**
- 直すのは常にフォルダ直下の `app.js` / `app.css` / `parser.js`
- 直したら `./sync.sh` を打つ（複製が配られる）→ `chrome://extensions` で拡張の🔄を押す

## ファイル

スマホ版（PWA）と拡張は**同じコードを共有**している。二重管理で片方だけ直す事故を防ぐため。

- `parser.js` … 振り分けロジック（共通）
- `app.js` … 画面と動き（共通）。**画面のHTMLもここが唯一の場所**
- `app.css` … 見た目（共通）
- `index.html` … スマホ版の器
- `chrome-extension/popup.html` … 拡張の器
- `sync.sh` … 共通ファイルを `chrome-extension/` に配るスクリプト
- `encoding.min.js` … Shift-JIS変換ライブラリ（encoding-japanese v2.2.0）
- `manifest.json` … ホーム画面追加用
- `icon.svg` / `icon-180.png` / `icon-192.png` / `icon-512.png` … ホーム画面アイコン（赤・封筒＋2本線）。作り直すときは icon.svg を直してPNGを書き出す

## 注意・既知の制限

- **ヘッダー行だけは公式テンプレートと突き合わせる**。もし違ったら「上級設定」で書き換えられるようにしてある（初回だけ確認）
- 氏名の判定はスコア方式。建物名を氏名と誤読する可能性がゼロではないので、振り分け結果は必ず目で見る（その場で直せる）
- クリックポストへのログイン・アップロードは自動化していない（規約とパスワードの問題）。上げるのは手で1タップ
- 入力の保存はlocalStorage。iOSは7日触らないと消えるが、リストは都度使い切る前提なので問題なし
